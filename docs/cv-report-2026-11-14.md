## 2. Methodology

**Quantitative (deterministic, reproducible):** each CV is scored against the market-prevalence dataset (`scripts/lib/scoring/market-insights.ts` — AI Engineer vs Automation Engineer vs Developer + AI study). Score = prevalence × placement (headline ×3, summary/keywords/skills ×2, experience/projects ×1). Must-have = prevalence ≥ 70%. Reproduce with `npm run audit:content` and `npx tsx scripts/dev/cv-report.ts`.

**Qualitative (recruitment screen):** each CV is graded as a **tech recruitment manager** running the first screen — the same frameworks the `jd` gate's qualitative layer uses: *6-second screen*, *knock-out requirements*, *ATS keyword search*, *STAR/CAR bullets*, *leveling signals*, *red-flag scan*, plus *truth lock* (source verification) and *parsing safety*. Scores 0–100 with evidence.
