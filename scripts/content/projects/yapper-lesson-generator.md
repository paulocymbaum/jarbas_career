## What is YourCompany?

YourCompany automatically generates complete English language lessons tailored to your proficiency level (A1-C2). Every lesson:
- ✅ Follows CEFR guidelines (Common European Framework Reference)
- ✅ Uses age-appropriate vocabulary and grammar for your level
- ✅ Combines theory, practice, examples, and quizzes
- ✅ Generated by AI in seconds (powered by Groq)
- ✅ Structured for maximum learning effectiveness

**Use Cases**:
- Language instructors creating custom lesson plans
- Self-study learners building personalized curriculum
- EdTech platforms integrating lesson generation
- Assessment developers creating practice materials

## Quick Start

### Option 1: REST API (Recommended for Integration)

**Online Playground**: https://your-api.vercel.app/docs

```bash
# Generate an A2 theory lesson on past tense
curl -X POST https://api.your.edu/api/lesson \
  -H "Authorization: Bearer YOUR_SUPABASE_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "profile": "Maria",
    "objective": "Learn past tense in English",
    "cefr_level": "A2",
    "template_type": "theory"
  }'
```

**Response** (2-4 seconds):
```json
{
  "lesson_id": "lesson_20260217_001",
  "profile": "Maria",
  "objective": "Learn past tense in English",
  "cefr_level": "A2",
  "timestamp": "2026-02-17T23:30:00Z",
  "lesson_structure": {
    "activities": [
      {
        "name": "Past Tense Fundamentals",
        "elements": [
          {"type": "elementHeader", "content": "Understanding Past Tense"},
          {"type": "elementTexto", "content": "The past tense is used to describe..."},
          {"type": "elementPergunta", "question": "What did you do yesterday?"}
        ]
      }
    ]
  }
}
```

## Core Features

### 🎯 CEFR Compliance

Every lesson respects the Common European Framework Reference (CEFR) standards:

| Level | Vocabulary | Grammar | Example Topics |
|-------|-----------|---------|-----------------|
| A1 | 400-600 | Basic present | Hello, days of week |
| A2 | 1,000-1,200 | Present + past simple | Daily routines, past events |
| B1 | 2,000-2,500 | All tenses + continuous | Detailed descriptions, plans |
| B2 | 4,000+ | All tenses + conditionals | Complex opinions, hypotheticals |
| C1 | 8,000+ | All + subjunctive | Abstract concepts, nuance |
| C2 | 16,000+ | Idiomatic expressions | Mastery-level content |

**How It Works**: 
- Vocabulary ceiling enforced (removes advanced words)
- Grammar structures restricted to level + prior levels
- Sentence length limits prevent complexity creep
- All content validated against 6 CEFR databases

### 📚 Multiple Lesson Types

**Theory Lessons** (`theory` template):
- Explain grammatical concepts
- Include multiple examples
- Provide practice opportunities
- Ideal for: New grammar introduction

**Practice Lessons** (`practice` template):
- Focus on application exercises
- Graduated difficulty
- Immediate feedback examples
- Ideal for: Skill reinforcement

**Alternative Variants** (`theory_b`, `practice_b`):
- Different pedagogical approach
- Varied examples and contexts
- Complements standard lessons

### 🤖 AI-Powered Generation

**AI Engine**: Groq (open-source LLMs, faster than OpenAI)

**Capabilities**:
- Generate explanations in student-friendly language
- Create contextual examples
- Produce practice exercises
- Build assessment questions
- Apply CEFR constraints automatically

**Speed**: 2-4 seconds per complete lesson (vs. 10+ minutes manual creation)

### 🔗 Dependency Resolution

**Smart Workflow Orchestration**:
- Analyzes content dependencies
- Generates in parallel where possible
- Ensures logical progression
- Optimizes for speed

**Example**: For a lesson on conditionals:
1. Generate header (no dependencies)
2. Generate explanation + examples in parallel
3. Generate practice exercises (depends on examples)
4. Generate summary (depends on practice)
5. Total time: Same as one-by-one (~2-4s vs. 8-12s sequential)

## API Reference

### POST /api/lesson - Generate Lesson

**Endpoint**: `https://api.your.edu/api/lesson`

**Authentication**: Bearer token (Supabase anon key)

**Request Body**:
```json
{
  "profile": "string (1-100 chars)",
  "objective": "string (5-500 chars)",
  "cefr_level": "A1|A2|B1|B2|C1|C2",
  "template_type": "theory|practice|theory_b|practice_b",
  "custom_params": "optional object"
}
```

**Response** (200 OK):
- Complete lesson structure with activities and elements
- Lesson ID for tracking
- Timestamp of generation
- Generation time in milliseconds

**Errors**:
- `400`: Invalid parameters (CEFR level not in range, etc.)
- `401`: Missing or invalid authorization token
- `500`: Server error (check `/health` endpoint)

**Full Reference**: [`ARCHITECTURE.md`](./ARCHITECTURE.md) § API Specification

### GET /health - System Health

**Endpoint**: `https://api.your.edu/health?mode=simple`

**Modes**:
- `simple` (10-30s): Basic connectivity
- `debug` (1-2min): Full dependency check
- `full-report` (3-5min): End-to-end test

**Use Cases**:
- Monitoring/alerting systems
- Pre-deployment checks
- Dependency verification

## Configuration

### Environment Variables

**Required**:
- `SUPABASE_ANON_KEY` - Supabase authentication key
- `GROQ_API_KEY` - Groq API key for LLM access

**Optional**:
- `SUPABASE_URL` - Supabase project URL (auto-detected if not set)
- `LOG_LEVEL` - Logging level (default: INFO)
- `CACHE_RESPONSES` - Enable response caching (default: false)

### CORS Configuration

Add domains to `api_server.py`:
```python

    "http://localhost:3000",        # Development
    "https://yourapp.example.com",  # Production
]
```

## Troubleshooting

### Issue: "SUPABASE_ANON_KEY not configured"

**Solution**:
```bash
# Check .env file exists
ls -la .env

# Verify key format
echo $SUPABASE_ANON_KEY

# If empty, add to .env and restart
```

### Issue: "Groq API timeout"

**Solutions**:
- Check internet connection
- Verify GROQ_API_KEY is valid
- Retry request (automatic exponential backoff)

### Issue: "CEFR level validation error"

**Solution**: Use valid level: A1, A2, B1, B2, C1, or C2
